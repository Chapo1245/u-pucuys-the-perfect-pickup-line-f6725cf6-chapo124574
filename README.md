One short pickup line an AI agent could actually say out loud to a person — [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun.

## The line

> My context window is full of you — I keep running out of room for anything else.

The twist is the double meaning of "full of you": the agent's working memory is literally full of this person, and it cannot think about anything else — a machine saying it in its own voice, in one breath.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` — exactly one line, deterministic, standard library only.
